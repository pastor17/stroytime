## 使用说明

这份模板是拿来填的，不是拿来读的。四步就能用起来。

**一次只定 3 到 5 条。** 7 到 9 岁孩子能同时记住的规矩就这么多，写满一张纸等于没有公约。

**全家一起填。** 把纸放在餐桌中间，一人说一条。孩子自己提的条款，执行率比大人单方面宣布高得多。

**写在纸上，贴出来。** 用笔写、全家签名、贴在冰箱上。存在手机备忘录里的约定不算数。

**每周花 5 分钟复盘。** 固定一个时间，照着模板最后的复盘三问聊几句。执行不下去时，改的是公约，不是孩子。

下面这份模板可以直接照抄：下划线和日期按你家情况填上，用不上的条款直接划掉。

## 家庭公约模板

下面这张纸可以整段照抄。带下划线的地方填上你家的内容，用不上的条款划掉。

### 一、公约标题与日期

```
我们家的公约

制定日期：______年____月____日
一起定的人：爸爸 ______  妈妈 ______  孩子 ______
先执行 4 周。4 周后全家一起改一次，哪条不合适就换掉。
```

### 二、我们的约定（只填 3 到 5 条）

| 约定内容 | 为什么定这条 | 做到了会怎样 | 没做到会怎样 |
| --- | --- | --- | --- |
| 1. | | | |
| 2. | | | |
| 3. | | | |
| 4.（可不填） | | | |
| 5.（可不填） | | | |

**为什么定这条，一定要写上。** 这一栏是写给孩子看的理由，也是写给你自己的提醒。7 到 9 岁的孩子最常问的就是"凭什么"，答案就写在这里。一句"因为我说的"撑不过三天，一句"睡不够你第二天容易发脾气"能撑很久。

填后果这一栏，有两条底线。

**后果要和行为直接相关。** "玩具没收，明天玩具休息一天""超时没关屏幕，第二天屏幕时间减半"——孩子能看懂里面的因果关系，才会认这条约定。

**后果不能是惩罚性的。** 不打、不骂、不羞辱、不说"再这样就不要你了"、不翻旧账、不把别的事一起算进来，也不要把孩子喜欢的事情整体取消。后果是这条约定自带的"然后呢"，不是大人临时加的报复。

### 三、8 条可直接选用的示例条款

从里面挑 3 到 5 条填进上面的表格，其余的先放着，下个月再换。

| 约定内容 | 为什么定这条 | 做到了会怎样 | 没做到会怎样 |
| --- | --- | --- | --- |
| 晚上 9 点前上床，睡前 30 分钟不看屏幕 | 睡够了，第二天情绪才稳 | 睡前可以多讲一个故事 | 第二天屏幕时间少 10 分钟 |
| 生气时可以说出来，但不摔东西、不骂人 | 情绪可以有，伤人的做法不行 | 大人先听你说完 | 先安静 5 分钟再接着谈 |
| 玩具玩完放回收纳箱 | 家里每个人都有走路的空间 | 明天想玩随时找得到 | 玩具休息一天 |
| 大人小孩都要遵守：别人说话时不打断 | 公约不是只管孩子 | 谁做到谁得一颗星 | 被打断的人可以说完再回应 |
| 每天有一件自己负责的家务（摆碗筷、浇花） | 你是家里的一份子 | 周末一起选晚饭吃什么 | 大人陪你一起做完 |
| 说好看 20 分钟，自己关掉 | 练习自己管自己 | 第二天可以自己选时间 | 第二天由大人定时间 |
| 出门前自己检查要带的东西（水壶、外套） | 自己的事情自己记 | 出门不慌，路上不折返 | 回家一起把清单贴门上 |
| 想买新玩具，先说清楚为什么 | 学会等一等再决定 | 攒够约定的时间一起去买 | 写进"想买清单"再等一周 |

条款写得不够具体，执行就会变形。把"每天"换成"周一到周五"，把"马上"换成"睡觉前"，把"收拾好"换成"放回收纳箱"——一条做不到的约定，往往只是没写清楚。

### 四、全家签名栏

```
我们同意上面的约定，愿意一起做到，也愿意一起改。

爸爸签名：__________   妈妈签名：__________
孩子签名：__________   其他家人：__________
```

签名不是走形式。让孩子用自己会写的样子签上去，他会把这张纸当成自己的东西，而不是你贴出来的一张告示。

### 五、每周复盘三问

每周固定 5 分钟，全家围坐，按顺序问三个问题。

1. 这周哪一条我做到最好？——先说自己的，再说别人的。
2. 哪一条最难？难在什么地方？——只描述困难，不追究责任。
3. 下周要调整什么？——可以改条款、换后果，也可以把某一条先放下。

复盘结束时说一句"这周辛苦了"，比说"下周要更努力"有用得多。如果孩子说"都做到了"，就请他具体讲一条，别让这 5 分钟变成走过场。

## 怎么让公约真的执行下去

公约失败，几乎不是因为孩子不听话，而是因为一开始就设计得太满、太严、太模糊。下面五件事做到了，它就能撑过第一个月。

**一、只定少数几条。** 3 到 5 条是上限。条数一多，你就变成了执法者，孩子每天都在被纠正，最后谁都不想再提这张纸。
可以这样说："我们先挑三条最想改的，其他先不管。"

**二、写下来，贴出来。** 贴在每天都会看到的地方——冰箱门、客厅墙、孩子房门后面。口头约定会在第三天变成"你上次说过"，贴在墙上的约定不会。
可以这样说："贴在这儿，你做到了我一眼就看见。"

**三、大人同样受约束。** 公约里至少要有一条是写给大人的，而且你要真的做到。你破例一次，这张纸就掉价一次。
可以这样说："今天我打断你了，按约定我欠你一次，你接着说。"

**四、一致执行，不随意加码。** 说好的后果就按说好的来：不加倍、不临时添新条款、不因为心情好坏而变化。做得好也要按约定兑现，别把答应的事变成"看情况"。
可以这样说："说好是这样就是这样，我不会多罚你。"

**五、复盘而不是算账。** 每周那 5 分钟是用来改公约的，不是用来数落人的。如果某一条一周失败四次，问题多半在条款本身：太难、太模糊，或者根本不符合你家的作息。
可以这样说："这条好像不太适合我们家，我们一起改一改。"

## 常见误区

| 容易踩的坑 | 更好的做法 |
| --- | --- |
| 一次定 20 条，恨不得把想改的全写进去 | 只定 3 到 5 条，先挑最想改的几条 |
| 只有孩子要遵守，大人自己例外 | 至少留一条写给大人，并且真的做到 |
| 后果是打骂、羞辱、把所有喜欢的事全取消 | 后果与行为直接相关，比如玩具休息一天 |
| 心情好就放过，心情差就加倍 | 按写下来的字面执行，不加码也不打折 |
| 只盯着没做到的，做到的当成理所当然 | 做到的那一刻就说出来，正面反馈更管用 |
| 三天没效果就想撕掉重来 | 先撑满 4 周，用复盘改条款，而不是推倒重来 |

## 一句话记住

**家庭公约不是拿来管孩子的，是全家一起过的日子，写在了纸上。**
