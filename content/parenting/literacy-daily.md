## 先看一个场景

周末下午，你在客厅刷到一条短视频，说现在的孩子读不懂古诗、也说不出几个历史故事。你抬头看了一眼，孩子正窝在沙发上刷手机，腿搭在茶几边上。

你心里有点急，放下手机，认真地对他说：“你别老看手机了，多读点书。”他“嗯”了一声，手指头没停。你又补了一句：“多读书对你有好处。”这回他连“嗯”都省了。

过了几天，你换了个说法：“要不我给你买几本书？”他说“随便”。书买回来摆在书架上，塑封一直没拆。你问他为什么不看，他说“没时间”——可你明明看见他一个晚上刷了两个小时视频。

你有点委屈：我也不是不管，我也提醒了，怎么一点动静都没有？其实你我都清楚，“多读书”这三个字，对一个十三四岁的孩子来说，几乎等于什么都没说。他不是不想变好，而是不知道具体该做什么。

## 为什么会这样

**第一，素养不是知识点的堆积，而是长期浸润出来的熟悉感。** 一个孩子听过一遍“一鼓作气”，可能第二天就忘了；但在饭桌上、在纪录片里、在一次次闲谈中反复遇到过，这个词就会变成他脑子里的背景。以后再遇到，他不慌，还能接得上话。素养的本质不是“记了多少”，而是“熟不熟、愿不愿意多看两眼”。熟悉感只能靠时间和次数慢慢堆出来。

**第二，突击式学习解决的是“考”，不是“养”。** 考试有范围、有截止日期，所以突击有效。文化素养没有大纲，也没有考卷，它的表现是：听到一个典故不觉得陌生，看到一幅画愿意站住多看一会儿，路过一座老房子会想知道它是谁建的。这些反应没法靠一周的集中努力换来，只能靠日子一天天慢慢长出来。你急着要结果，孩子只会感到被考核。

**第三，青春期孩子最抗拒的是“被安排着成长”。** 十三四岁的孩子自我意识很强，凡是明确指向“教育他”的事，他都本能地想退一步。你越说“这对你有好处”，他越觉得这是你的目标。所以这个阶段真正有效的入口，是“不刻意”——一起看一集片子、饭桌上顺口聊几句、冬至一起包顿饺子。事情本身有意思，他才愿意参与；一旦感觉到在被教，门就关上了。

**第四，家庭的优势恰恰在于它是生活，不是课堂。** 学校负责系统的知识，家里能提供的是另一件东西：没有考核的、慢节奏的、带着温度的接触。这也意味着你不需要懂多少，只要把它放进日常，坚持得比孩子久一点。

## 可以这样做

这四件小事不用全上，先挑一件试一个月。它们的共同点是：不额外占时间，不设考核，做的时候像过日子，不像上课。

**第一件：一起看一部纪录片或文化节目，看完聊十分钟**

怎么做：挑一集自然、历史、传统手艺类的纪录片或文化节目，时长四十到五十分钟，安排在周末晚上，当“家庭节目”来看。看之前不必预告，看的时候不要中途讲道理，看完聊十分钟就散场。不要求记笔记，不要求写观后感。你在旁边和他一起看——你如果只是在旁边刷手机，他一眼就能看出来。

频率：一周一次，或者两周一次，固定在同一个时间段，比如周六晚饭后。一次就够，不要变成每天的任务。

怎么开口：千万别说“看完说说你学到了什么”，这句话一问，气氛就变成考试了。可以问：“刚才那个画面你印象最深的是哪个？”先问画面和感受，不问结论。你还可以先说自己的一句：“我以前不知道，原来一件东西要修这么久。”把话头打开，他接不接都行。

**第二件：饭桌上讲一个成语或历史典故的来龙去脉**

怎么做：一周两次，每次三到五分钟，就在饭桌上，不专门开课。重点不是解释成语的意思，而是讲“来龙去脉”——谁、在什么情况下、为什么这么说。比如“一鼓作气”出自《左传》里的曹刿论战：齐军擂鼓进攻，鲁庄公想马上迎击，曹刿说不行，等齐军擂过三通鼓才让鲁军出击，结果大胜。事后曹刿解释，作战靠的是勇气，“一鼓作气，再而衰，三而竭”。故事讲完，这四个字就不是要背的词语，而是一个看得见的画面。

准备：你不必什么都懂。头一天晚上花两分钟查一下出处，或者干脆说“我昨天看到一个词，挺有意思”。讲错了也不要紧，孩子更在意你有没有兴趣，而不是你讲得对不对。

怎么开口：讲完不要追问“记住了吗”。可以留个尾巴：“你说他当时怎么想到的？”或者“还有一个说法不太一样，明天再说。”也可以反过来，让孩子讲一个他在课上看到、在视频里刷到的故事，你认真听，多问细节——他讲一遍，比你讲三遍有用。

**第三件：一年里跟着节气或节日做一件小事**

怎么做：二十四个节气不用都做，一年挑四个，一个季节一个。每个只做一件具体的事：立春那天在阳台种一盆葱或薄荷；清明前后出门走一走，顺口说说清明既是节气也是节日；夏至那天记下日落时间，过一个月再记一次，让他自己看出白昼在变短；冬至那天全家一起包一次饺子，民间有“冬至不端饺子碗，冻掉耳朵没人管”的老话，白昼最短也是那天。做完在冰箱上贴张纸，写上“立春·种葱”“冬至·包饺子”。

频率：一年四次，做的时候多聊两句，不做的时候不提。

怎么开口：把“学”藏进动作里。“今天冬至，白昼最短，咱们包顿饺子。”节气怎么来的、古人怎么用它安排农活，你顺口说两句就好，说不出来也完全没关系。孩子记住的往往不是知识，而是“这一天和平时不一样”。

**第四件：把家里的老物件和老故事讲给孩子听**

怎么做：找一个具体的东西当引子——老家带来的搪瓷缸、一台旧缝纫机、一本相册、一叠旧车票、一封手写的信。把它拿出来放在桌上，不用铺垫，就从他看得见的地方说起：照片里是谁、当时在哪儿、那年家里一个月挣多少钱、一件衣服怎么穿三年、你小时候上学走多远的路。重点讲细节和你当时的心情，不要只讲“我们那时候多苦”。

频率：不用定期，一个月一次就够，回老家或过年整理东西的时候顺手做最好。

怎么开口：“这张照片上抱着我的人是你太姥姥，那年我六岁。”“这台缝纫机是你奶奶的，你爸小时候的裤子都是它踩出来的。”如果他愿意接着问，你就往下讲；如果他把手机放下了，那就是最好的信号。还可以请他帮忙：把老照片拍下来，标上时间和人名，或者录一段老人讲故事的录音。他动手整理的时候，其实已经在做一件很“文化”的事了。

## 常见误区

| 容易踩的坑 | 更好的做法 |
| --- | --- |
| 把素养当科目，看完就问“记住了吗” | 只聊感受，先问“哪个画面你印象最深” |
| 只买书，自己不看也不陪着看 | 一起看一集、一起聊十分钟，你先说一句自己的感受 |
| 天天说“多读书”，却不给具体入口 | 一次给一个具体动作：“周六晚饭后一起看一集” |
| 一讲典故就讲成大段历史课，超过十分钟 | 饭桌上三到五分钟，只讲一个人、一件事、一个画面 |
| 只在孩子表现好时才聊这些话题 | 平时就聊，不评价、不考问，让话题变成家常话 |
| 觉得家里没什么可讲，老物件早丢了 | 一张旧照片、一句方言、一道家乡菜都是入口 |

## 如果试了没效果

**一、先降门槛，不要加码。** 如果约好的节目他两次都不来，多半不是他不感兴趣，而是这件事看起来太重了。把量砍到最小：不要求看一集，只看开头十分钟；不要求聊十分钟，只聊一句。也可以换个时间，改成他吃完夜宵、最放松的时候。孩子拒绝的往往是“被安排”，不是内容本身。

**二、从他已经在乎的东西进去。** 十三四岁的孩子一定有自己着迷的东西：某款游戏里的古代建筑、球鞋背后的设计、一条街的名字是怎么来的、某段外国历史的电影。你不用把话题硬拽回课本，顺着兴趣往外延一点：他喜欢古建筑，就聊木头为什么不用钉子；他爱看球，就聊这座城市一百年前是什么样。兴趣本身就是最好的入口，从里面往外扩，比硬推容易得多。

**三、借别人的嘴，换一个人来讲。** 同一件事，家长说十遍不如外人说一遍。可以是博物馆的讲解员、会做手艺的亲戚、会讲故事的老人，也可以是纪录片里修复文物的人。你要做的不是讲，而是创造一次“遇见”。还有一招很管用：让他讲给你听。请他教你一个你不知道的典故，或者把看过的那集讲给你——讲出来，才真正长在他身上。

## 一句话记住

**文化素养不是补出来的，是一起过日子过出来的。**
