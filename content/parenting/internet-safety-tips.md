## 先看一个场景

孩子十岁，手机里已经有了自己的社交账号。有一天他兴奋地跑过来："妈妈/爸爸，有个游戏里的人想加我好友，他说他可以教我打游戏。"

你心里"咯噔"一下。你想说"别加"，可你没法二十四小时盯着他。你也不想，有一天他在网上遇到一个"看着很和善"的人，却连"我有点不舒服"都不敢告诉你。

这份指南想给你一套"底线 + 技巧"：底线是"无论如何不能碰"的几条，技巧是"怎么让他愿意跟你讲"的几个动作。

## 为什么会这样

10—12 岁的孩子开始有自己的"网络社交圈"，他的朋友在群里、在游戏里、在视频里。你如果只说"不许上网"，他会记住"不能"，但不会记住"为什么"，更不会记住"遇到不舒服的事，我可以告诉你"。

而且，网络上的"陌生人"和现实里的"陌生人"不一样——你不知道屏幕后面是大人还是小孩、是善意的还是恶意的。你需要的，不是替他上网，而是给他一套"判断标准"和"求助通道"。

## 可以这样做

**5 条底线（无论如何不能碰）：**

1. **不透露地址、学校、姓名（全名）、照片。** 网上的人可能不在你身边，这些信息一旦被拿走，后果不可逆。
2. **不见网友。** 不管网上聊得多投缘，不单独见。如果要见，必须有家长在场、在公共场所。
3. **不点陌生链接、不下载陌生文件。** 很多"免费皮肤""破解版游戏"是钓鱼，点了就可能泄露信息或中病毒。
4. **遇到不舒服的事，立刻说。** 这是最重要的一条。如果网上有人让你不舒服、让你"保密"、想让你发照片、想带你去某个地方——立刻关屏，告诉你。这不是告状，是保护自己。
5. **屏幕时间约定。** 每天多少时间、什么时段、能不能在饭桌和睡觉前用——提前说好，不是"没收"，是"约定"。

**3 个技巧（怎么让他愿意配合）：**

1. **一起上网。** 不是"监督"，是"陪伴"。你坐在旁边，他给你讲讲他在玩什么、在跟谁聊。当他习惯了你"在旁边"，他就不会觉得上网是一件"偷偷摸摸"的事。
2. **定期看浏览记录（提前告诉他）。** 不是"偷偷查"，是"我每周会看一次"。让他知道你在看，他就不会觉得"你随时在查我"。重点是"透明"，不是"监视"。
3. **教他"不舒服就关"。** 给他一个具体的动作：如果屏幕上出现让你不舒服的东西（图片、文字、私信），你不需要"想清楚"，你只需要做一件事——关屏，告诉大人。把这个动作练熟，他真遇到时才不会愣住。

## 可以这样说

- "网上的人，你不知道他是不是他说是的那样。所以，地址、学校、全名、照片，这些不告诉任何人。"
- "不管网上聊得多投缘，不见网友。要见，必须我在场、在公共场所。"
- "链接和文件，不认识的，不点、不下。'免费'和'破解'，十有八九是钓鱼。"
- "如果你在网上遇到让你不舒服的事，你不需要'想清楚'，你只需要做一件事：关屏，告诉我。这不是告状，是保护自己。"

## 常见误区

| 常见说法 | 更好的做法 |
| --- | --- |
| "不许用手机/不许上网" | 完全禁止只会让他"偷偷用"。给他底线（5 条）+ 技巧（3 个），让他知道"能做什么、不能做什么、遇到事可以找谁"。 |
| "我会偷偷看他的手机" | "偷偷查"会摧毁信任。提前告诉他"我会定期看"，让他知道边界，他反而更愿意跟你讲。 |
| "他这么小，不会遇到危险的" | 10—12 岁已经是"网络社交"的起点。危险不是"等他长大"才来的，是现在就开始的。 |
| "只要他不说，我就当他没事" | 明确告诉他："遇到不舒服的事，你'不说'不是我的错，是你的选择。但如果你说了，我不会怪你，我会帮你。" |
| "只讲'不要做'，不教'遇到事怎么办'" | 底线是"不能碰"，技巧是"怎么求助"。两条都要，他才有底气。 |

## 一句话记住

**孩子上网安全，不是"不许上"，是"5 条底线 + 3 个技巧"——底线让他知道"不能碰什么"，技巧让他知道"遇到事可以找你"。真正的保护，是让他愿意开口，而不是让他害怕开口。**
