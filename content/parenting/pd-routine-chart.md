## 先看一个场景

早上七点，你站在门口，书包已经拎在手上。孩子在餐桌前咬着面包，眼睛盯着地板，一口一口磨。

「快点，还有十分钟。」他没抬头。

「说了多少遍了，先穿袜子再吃饭。」他慢慢放下筷子，走回房间，过了三分钟才出来，袜子还拿在手里。

「你今天又迟到了知道吗？」你的声音开始往上走。他把袜子往沙发上一扔：「我不去了！」

最后你替他穿上外套、塞好水壶、拉着他出门。电梯里你还在喘气，他板着脸不说话。到了楼下，你忽然觉得浑身没劲——这已经是本周第四次了。

你并不想吼。你只是怕迟到，怕他挨批评，怕事情做不完。可是每天都从催促开始，从争吵结束，你累，他也委屈。明明出门只需要二十分钟的事，为什么要花掉你们早晨所有的耐心？

## 为什么会这样

先看一件事：你催得越频繁，孩子越慢，这几乎是一条规律，而不是他故意跟你作对。

**第一，催促很容易变成权力之争。** 「快一点」表面上是提醒，孩子听到的却是「你的事由我决定」。七八岁的孩子正需要确认「我能管好自己」，当他发现自己没法决定开始的时间，他还能决定什么呢？于是他决定慢。慢是他手里仅剩的权力。

**第二，催促把责任转移到了你身上。** 你一边喊，一边替他着急，等于告诉他：这件事是我着急，不是你的事。真正该管这件事的人被推到一边，只剩下你一个人在推。

**第三，孩子需要的是能自己看见的步骤，而不是别人的声音。** 早晨是一长串动作：起床、上厕所、洗脸、穿衣、吃饭、整理要带的东西、穿鞋出门。对你来说这已经是自动的流程，对他还是一片模糊。你喊「快点」，他其实不知道该快在哪一步。

正面管教把日常惯例表当作一个常用工具，它的巧妙之处在于：**把「人对人的命令」变成「人对约定的执行」**。提醒你的不再是妈妈的声音，而是墙上那张他自己画的表。冲突从「你和我」之间，挪到了「我和我的计划」之间。孩子不必通过反抗你来证明自己，也就没有那么多仗要打。

另一个关键是让他参与。一起讨论、一起排序、让他画或贴——他参与了制定，那张表就成了他的作品，执行的是自己的约定，而不是服从别人的命令。孩子对「我做到过」的体验越具体，自我管理就越站得住。

## 可以这样做

### 第一步：先只做一个时段，不要一次全铺开

最容易失败的做法，是回家做一张从起床到睡觉的完整时间表，头三天兴致勃勃，第四天谁也不看。改变一件事已经耗神，别一次改十件。

挑最让你头疼的那个时段。你的情况是早晨，那就只做早晨。其他时段先维持原样，等早晨顺了再说。

**可以这样说：** 「早上我们俩都太赶，我想跟你一起弄个东西，让早上轻松点。就管早上，别的不管。」

### 第二步：和他一起列步骤，让他画出来

坐在他旁边，你问，他答。让他说，哪怕顺序奇怪，也先记下来。然后请他画：起床画一个小人坐起来，整理要带的东西画一个书包。写不好字没关系，画画和贴纸都算。

这一小时的价值不在于表有多好看，而在于「这是我的表」这个感觉。

**可以这样说：** 「早上从睁眼到出门，你都要做哪些事？你说，我来记。」「这几件事你想画成什么样？」

### 第三步：步骤要小到一眼就能做到

「洗漱」太大了，孩子不知道从哪下手。「挤牙膏、刷牙、洗脸」才是能做的动作。「准备出门」也太笼统，「穿外套、背书包、穿鞋」才是三步。七八岁的孩子对时间的感觉还很模糊，对动作却很具体。

**可以这样说：** 「『收拾好』有点大，我们拆成几件小事好不好？」

### 第四步：贴在看得见的地方，让表来提醒

贴在洗手间镜子旁边、房间门背后或者餐桌边上——他每天必经、抬头就能看到的地方。位置固定，不要今天贴这里明天贴那里。

**可以这样说：** 「你想把它贴在哪儿？贴在你一抬头就能看见的地方。」

### 第五步：你只提醒表，不催人

这是最难、也最关键的一步。以前你说「快点」，现在你说「看看表，现在到哪一步了」。句子的主语从「你」换成了「表」，火药味就淡了一半。

如果他还是不动，让结果说话，而不是把音量加大。可以平静地说一句「七点四十出门，来不及就带着早餐走」，然后真的执行——不追加责备，也不翻旧账。做到的部分记得指出来。

**可以这样说：** 「我不催你了，表在这儿，你自己看。」「现在七点三十五，你还有五分钟。」

### 第六步：执行一两周后，一起复盘调整

表不是判决书，是可以改的。一两周后找个轻松的时候问问他：哪一步最卡？哪一步其实不用那么久？然后当场改，划掉、加一条、调顺序都行。允许修改，表才活得下去。

**可以这样说：** 「这一周哪一步最烦？我们把它改简单点。」

### 早晨惯例表示例

一起做的时候可以照着这个结构，但具体内容和顺序请让孩子自己说、自己定。

| 顺序 | 要做的事 |
| --- | --- |
| 1 | 闹钟响，坐起来，把脚放到地上 |
| 2 | 上厕所、洗手 |
| 3 | 自己穿好衣服（前一晚选好的那套） |
| 4 | 挤牙膏、刷牙、洗脸 |
| 5 | 坐到餐桌前吃早饭 |
| 6 | 把碗筷放到水池边 |
| 7 | 整理要带的东西：水壶、当天要用的物品放进书包 |
| 8 | 穿外套、穿鞋、背书包，出门 |

注意第 1 步写得非常小——「坐起来，把脚放到地上」。这不是啰嗦，而是把最难启动的那一下变成一个明确、几乎不可能失败的动作。第 3 步前面加一句「前一晚选好衣服」，可以把早晨的犹豫提前到睡前解决。

## 常见误区

| 容易踩的坑 | 更好的做法 |
| --- | --- |
| 一次做完从早到晚的整张表 | 先只做一个时段，早晨顺了再加睡前 |
| 家长自己画好、打印出来贴上去 | 一起列步骤，让他画或贴，表里有他的痕迹 |
| 步骤写得太笼统（洗漱、收拾好） | 拆成「挤牙膏、刷牙、洗脸」这样一眼能做的动作 |
| 把表当成考核表，用来数落和比较 | 只用来提示下一步，做得好的地方具体指出来 |
| 表贴上了，家长还是忍不住在旁边催 | 提醒表，不催人：「看看表，现在到哪一步了」 |
| 表定下来就不许改，改了就是没做到 | 一两周复盘一次，哪步卡就改哪步 |

## 如果试了没效果

**第一，可能表太大，退回一个更小的起点。** 如果八步的表他一动不动，就只保留三步：起床、刷牙、出门。做到之后再慢慢加回来。成功的体验比完整的计划重要得多。

**第二，可能他卡在某一步，而不是不想做。** 有些看起来磨蹭，其实是那件事有困难——扣子不会扣、鞋带系不好、书包太重塞不进去。陪他练一练那个动作，比催十遍有用。

**第三，可能你们都需要一点缓冲时间。** 如果每天都在和时间赛跑，就把出门时间往后挪十分钟，或者把起床提前十分钟。惯例表解决的是「由谁提醒」，解决不了「时间本来就不够」。把时间留够，你们才有余地去练习，而不是每一分钟都在救火。

如果一两周后早晨依然每天吵架，说明还有别的事在起作用，比如睡得太晚、早上情绪本来就紧。那时候先处理睡觉和情绪，表可以暂时放一放——工具是拿来用的，不是拿来完成任务的。

## 一句话记住

**把「我催你」换成「一起定、表来提」——孩子的早晨，归根结底是他自己的早晨。**
