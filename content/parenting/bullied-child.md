## 先看一个场景

晚上七点，孩子进门把书包往沙发上一扔，一句话不说。你问怎么了，他憋了半天才挤出一句：「他们又拿我的东西，还笑我。」你胸口一下子烧起来，心疼、愤怒，还有一点说不清的无力。你几乎是脱口而出：「他打你，你就打回去啊！你怎么不还手？」

他没接话，头低得更下去，转身进了房间，把门带上了。你站在客厅里，越想越气，甚至想立刻给老师打电话问个明白。可你隐约觉得，刚才那句话，让事情反而更沉了一点。

其实，孩子能开口告诉你这件事，已经很不容易。说出这句话，他得先越过三道坎：怕同学报复，怕大人说他没用，怕你冲到学校把事情闹大。所以听见「我被欺负了」的那一刻，真正决定后面走向的，不是你有什么办法，而是你头三十秒的反应。

## 为什么会这样

「打回去」听起来解气，为什么常常行不通？

**第一，它把孩子推到更孤单的位置。** 欺凌往往不是一对一，而是几个人、有围观、有力量差。让孩子去还手，等于让他独自去打一场他打不赢的仗。真冲突起来，受伤的可能是他，事后被一起处理的也可能是他。

**第二，它悄悄把责任转到孩子身上。** 「你怎么不还手」「你怎么不早说」，字面上在教方法，孩子听到的却是：我被欺负，是因为我太弱、我做得不好。这种羞耻感，比那几下推搡更难受，也更容易让他从此闭嘴。

**第三，「忍一忍就过去了」同样不行。** 它等于告诉孩子，他的感受不重要，求助是不被允许的。忍久了，他不再跟你说，因为「说了也没用」。而持续被欺负又无人回应，最伤的是他对自己价值的判断。

还有一层容易被忽略：孩子不敢说，常常不是不信任你，而是太了解你。他见过你为他着急的样子，怕你直接找学校、怕你打电话给对方家长、怕第二天全班都知道「他告老师了」。所以他宁可自己扛。

这些处境决定了顺序：先让他感到安全、被相信，他才有勇气把事实说清；事实清楚了，你才判断得出这是偶发摩擦还是持续欺凌、要不要学校介入。跳过前一步直接给方案，你拿到的信息往往是残缺的，而他会觉得，说了也白说。

## 可以这样做

下面六步按顺序来。不必一次做到完美，做到第三步，事情的方向通常就已经变了。

**第一步：先接住情绪，明确告诉他「这不是你的错」。**

放下手机、关掉电视，坐下来和他平视，别站着问。今天哪怕只做这一件事，也值得。不要急着追问细节，先回应他的感受，让他知道说出来是安全的。

可以这样说：「谢谢你告诉我，这一定很难开口。」「你被这样对待，我很心疼。」「这不是你的错。」

**第二步：把事实问清楚，但不追问细节。**

像记者一样问「谁、什么时候、在哪里、还有谁在、第几次了」，而不是像法官一样问「你当时做了什么」。不要追问羞辱的具体过程，不要让他反复复述每一个字——重复讲述会让他再受一次伤。可以随手记在手机备忘录里，时间和经过越具体，后面和学校沟通越有用。

可以这样说：「这事大概是从什么时候开始的？」「还有别的同学也被这样对待吗？」「你希望我怎么帮你？」

**第三步：判断性质，再决定要不要请学校介入。**

问自己三个问题：是不是反复发生？力量和人数上是否明显不对等？孩子有没有出现怕上学、肚子疼、绕路走、情绪明显低落这些反应？三条里有一条是「是」，就不再是同学间的小摩擦，需要学校介入。如果只是偶发口角，孩子情绪平稳，可以先教他自己应对，同时保持观察，不必立刻升级。

可以这样说：「我先弄明白事情是什么程度，再决定怎么做，你放心。」

**第四步：教三种具体应对，而不是「打回去」。**

要给孩子的是可执行的动作，不是一句态度。一是大声、短促地制止，声音大到周围人听得见；二是立刻离开，走向人多的地方或老师附近；三是事后第一时间告诉一个可信任的大人。要提前和他讲清楚：求助和保护自己是同一件事，遇到危险时说出来不丢人，也不算「打小报告」。如果他愿意，在家用角色扮演练两遍，练过的话，真到那一刻才说得出口。

可以这样说：「你不需要打赢他，你只需要安全地走开。」「大声说『停下，我不喜欢这样』，然后马上走。」

**第五步：和学校沟通，用「事实加诉求」的方式。**

联系班主任，语气平稳，先陈述事实，再讲你的请求：请老师了解情况、留意课间和放学路段、并在不公开点名的情况下处理。避免在班级群里公开点名，也尽量别直接去找对方家长理论——那很容易变成两个家庭的对抗，最后难做的是孩子。沟通完约定一个反馈时间，比如一周后再碰一次。

可以这样说：「我想跟您反映一个情况，也想请您帮个忙。孩子近来多次被几位同学拿东西、起外号，他最近不太敢去课间。我不希望公开处理让他更难受，只想请您帮忙留意，也想知道学校一般会怎么处理。」

**第六步：事后持续跟进，别当成一次就解决的事。**

头两周最容易反复。每天留十分钟单独聊聊，但不要天天追问「今天有没有人欺负你」——那会让他每天都重新想起这件事。换成开放的问题，比如今天最开心和最不开心的事各一件。同时留意睡眠、吃饭和写作业的状态。如果情况好转，明确肯定他：「你愿意说出来，事情才有转机，你做得对。」

可以这样说：「这件事我会一直跟着，你不用一个人扛。」「我们先看一周，如果还这样，我们再一起想办法。」

## 常见误区

| 容易踩的坑 | 更好的做法 |
| --- | --- |
| 「你怎么不早说？」 | 「谢谢你今天告诉我，现在说也来得及。」 |
| 「是不是你先惹的？」 | 「不管之前发生过什么，被这样对待都不该由你承担。」 |
| 「他打你，你就打回去。」 | 「先走开、大声制止、告诉大人，安全比输赢重要。」 |
| 立刻冲去学校，或直接找对方家长理论 | 先问清事实，再和班主任约定处理方式与反馈时间 |
| 「这点小事，忍一忍就过去了。」 | 「这件事我在意，我们一起看接下来怎么办。」 |
| 问过一次就不再提 | 主动跟进一两周，好转后也明确肯定他 |

## 如果试了没效果

先别急着怀疑自己。反复发生的欺凌，很少靠一两次沟通就彻底停止。可以试这几条：

**一是提高沟通层级。** 如果班主任回应含糊，或情况照旧，就把事实按时间顺序整理好，约见年级负责人或学校负责学生工作的老师，必要时书面提交并保留沟通记录。**二是帮孩子找到身边的同伴。** 鼓励他和一两位合得来的同学结伴走、结伴活动，人多的场合，这类事情发生的概率会明显下降。**三是稳住家里的节奏。** 保持作息、运动和一起吃饭的时间不被打乱，孩子有了稳定的后方，才有力量应对白天的事。

同时留意必须立刻升级处理的信号：情况持续两周以上没有改善；出现推打、抓伤、物品被损坏等身体伤害；孩子明确表示不想上学、开始逃课；出现失眠、噩梦、长时间情绪低落；说出「我不想活了」这类话，或有自伤行为。出现任何一条，请当天联系学校要求正式处理，并寻求专业心理帮助，不要等它自己好。

## 一句话记住

**孩子被欺负时，他最先需要的不是你的办法，而是你的相信——先稳稳接住他，再一起去解决问题。**
