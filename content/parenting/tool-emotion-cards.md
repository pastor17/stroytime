## 使用说明

这张卡不是拿来看的，是拿来在卡壳那一刻照着念的。四到六岁的孩子词汇还撑不起感受：他明明心里翻江倒海，能说出口的只有一句「不开心」。你要做的不是追问出原因，而是先递给他一个更准确的词。

什么时候用：他哭、他摔东西、他闷坐在角落、他反复说同一句「不开心」的时候。不用等情绪过去，也不用挑一个「合适的时机」，正在发生的那一刻就是最好的时机。

怎么开口：蹲下来和他平视，先说你看到的事实，再猜一个可能的感受。「你搭了很久的塔倒了，你把它推开了——你是不是很生气？」猜错也没关系，他会纠正你，而纠正本身就是在说出感受。

说完要等。等他三到五秒，不要马上接下一句，也不要马上给方案。他不说话，你就再补一句：「想不到词也没关系，我陪你坐一会儿。」

## 16 句可以直接照念的话

下表按场景排列。第二列是你最容易脱口而出的话，第三列是可直接照着念的替换句，第四列说明它为什么管用。不必全记，先挑最近最常卡壳的两三行抄进手机备忘录。

| 场景 | 别这样说 | 换成这样说 | 为什么有效 |
| --- | --- | --- | --- |
| 生气（搭好的积木被碰倒） | 「有什么好气的，重新搭一个不就行了。」 | 「你的塔被碰倒了，你特别生气。生气是可以的，你可以说出来，也可以跺两下脚，我在这儿陪你。」 | 先命名再允许，孩子才不必用摔东西来替你表达。情绪有了名字，强度就会降一档。 |
| 难过（玩具坏了、小伙伴回家了） | 「别哭了，多大点事。」 | 「你很难过，眼泪都掉下来了。难过的时候可以哭，我抱着你，等你想说的时候再说。」 | 哭被允许，孩子就不必把难过藏起来。被陪着哭完的那一次，比被劝住的十次都管用。 |
| 害怕（怕黑、怕雷声、怕影子） | 「这有什么好怕的，都是假的。」 | 「你有点害怕，那个影子让你心里发紧。我陪你过去看一眼，灯也开着，你随时可以叫我。」 | 否认恐惧，孩子只会学会独自硬扛。承认害怕再补上安全感，他才敢往前一步。 |
| 委屈（被冤枉、玩具被抢反被说） | 「谁让你不早说，现在哭有什么用。」 | 「你觉得很委屈，明明不是你先动手的。被误会确实很难受，你慢慢说，我在听，先不打断你。」 | 委屈最怕不被相信。先站在他这边把话听完，他才愿意讲出细节。 |
| 嫉妒（同伴或弟弟妹妹被夸奖） | 「你是哥哥了，还吃这种醋，羞不羞。」 | 「你也想被抱一抱，看到别人被抱，你心里有点酸。这很正常，你也过来，我抱抱你。」 | 嫉妒被指责会转成暗中的争宠，被说出来反而会淡下去。 |
| 失望（说好的公园去不成了） | 「不去就不去，下次再说，别摆脸。」 | 「你盼了那么久，结果去不成了，你特别失望。失望的时候不想笑，是可以的，我陪你待一会儿。」 | 失望需要一个正式的承认。被承认过的失望，孩子才有力气接受现实。 |
| 紧张（见陌生人、去陌生的地方） | 「有什么好紧张的，你平时不是挺能说吗。」 | 「要去一个不熟的地方，你心里有点紧张，手心是不是凉凉的？我拉着你的手，我们一起进去。」 | 把紧张落到身体上，孩子就多了一个抓手，而不是被整团情绪吞掉。 |
| 羞愧（尿床、打翻东西、被同伴笑） | 「这么大了还这样，说出去都丢人。」 | 「这件事让你觉得不好意思，脸都热了。这谁都可能遇到，我们一起收拾，别人不会一直记得。」 | 羞愧最容易伤到「我这个人好不好」。把事和人分开，他才敢面对。 |
| 兴奋（明天要出去玩、收到惊喜） | 「别跳了！安静一点，吵死了。」 | 「你现在太开心了，开心得停不下来。你可以跳三下，然后我们坐下来，把明天要带的东西数一遍。」 | 兴奋也需要被命名。给一个出口和一个小边界，比让他硬压回去管用。 |
| 无聊（下雨出不去、玩具都玩腻了） | 「无聊就去看书，别来烦我。」 | 「你现在觉得无聊，时间过得好慢。我们一起想三件现在能做的事，你来挑一件。」 | 无聊是孩子学着自己找事的起点。先接住再给一点选择，他慢慢能自己启动。 |
| 想要得不到（当场要买某样东西） | 「不行就是不行，再哭我们就走。」 | 「你特别想要那个，现在得不到，你很不甘心。今天确实不买，你可以难过一会儿，我在这儿等你。」 | 拒绝可以坚定，态度要连着。他学到的是「想要可以，但不能都要」，不是「有愿望就是错的」。 |
| 被拒绝（想加入游戏，同伴说不要你） | 「人家不跟你玩，你就自己玩呗，有什么好哭的。」 | 「你想跟他们一起玩，被拒绝了，心里很难受。被拒绝真的会疼，我们先在这儿坐一会儿，再想想还能做什么。」 | 把被拒绝的疼说出来，孩子才不会把它翻译成「我不够好」。 |
| 被误解（好心帮忙被当成捣乱） | 「肯定是你先惹的人家，不然人家为什么说你。」 | 「你本来是想帮忙，结果被当成捣乱，你觉得很冤。我信你说的，你把经过慢慢讲给我听。」 | 被误解时孩子最需要一份不加条件的信任。先信他，再一起还原当时发生了什么。 |
| 累（玩了一整天、走不动了） | 「才走这么点路就累了？刚才不是挺能跑。」 | 「你今天玩了一整天，现在累得什么都不想做了。累了就会想哭，我们先歇一会儿，什么都先不弄。」 | 很多「无理取闹」其实是疲劳的信号。把累命名出来，你也少发一次火。 |
| 孤单（同伴都不在、没人陪他玩） | 「我不是在家吗？怎么还孤单。」 | 「你想有人一起玩，现在只有你一个人，心里空空的。我陪你十分钟，你想说话，或者想靠着我，都行。」 | 孤单说不出口就会变成黏人或闹脾气。命名之后，他才不必用行为来喊你。 |
| 说不清（只会反复说「不开心」） | 「到底怎么了？你不说我怎么知道！」 | 「你说不开心，我知道你现在很难受，只是还找不到词。我来猜几个：是生气，是难过，还是有点怕？你点头就行。」 | 说不出不是不想说，是词不够。给出选项，他只要点头就已在学着命名。 |

## 两个通用原则

十六句话看着多，背后只有两条。记住原则，你就能自己造句子，不必依赖这张卡。

**原则一：先命名，再解决。**

原句：「别哭了，不就是积木倒了吗，重新搭一个就好。」
换成：「积木倒了，你搭了那么久，特别难过。先难过一会儿，等你愿意了，我们再一起看看怎么搭得更稳。」

为什么这样更有效：孩子情绪冲到顶上的时候，听得进道理的那部分能力是关着的。你先替他把感受说出来，等于告诉他「我看见了」，情绪有人接住，才降得下来。顺序很关键——先感受后事情，孩子能听进去；反过来说，道理再对，也是撞在一堵墙上。所以命名不是绕路，它是让后面的话有机会被听见的第一步。还有一点：命名的句子要短，一次只给一个词，不要一口气列五个感受让他选。

**原则二：允许情绪不等于同意行为。**

原句：「你生气就可以打人吗？以后不许生气。」
换成：「你很生气，这个我懂。手不可以打人，这是底线。你可以捶枕头，也可以大声说『我生气了』，但不能打到别人身上。」

为什么这样更有效：孩子分不清「我生气」和「我打人」，这两件事需要你替他分开。如果你连情绪一起禁止，他学到的不是「不打人」，而是「有情绪是危险的，要藏起来」——情绪不会消失，只会换个更隐蔽的方式出来。正确的做法是双线并行：情绪那条线全部放行，行为那条线守住底线，并且立刻给一个可以替代的出口（捶枕头、大声说出来、来找你）。很多家长怕一承认感受就变成妥协，其实恰恰相反：感受被接住的孩子，反而更容易接受「这件事今天就是不行」。同一句话里既有理解也有边界，孩子才不会把规矩听成抛弃。

## 常见误区

| 误区 | 为什么不管用 | 可以怎么改 |
| --- | --- | --- |
| 追着问「你到底怎么了」 | 情绪上头时孩子调不出词，追问只会变成第二重压力 | 先替他命名：「你是不是很生气？」给词，不给压力 |
| 一说出感受就马上讲道理、给方案 | 前面那句等于白说，孩子听到的仍是「快别哭了」 | 命名之后停三到五秒，等他自己往下说 |
| 只在他哭闹的时候才用这些话 | 孩子会把「说感受」和「挨批评」连在一起，越说越少 | 平静时也用：「今天塔搭好的时候，你是不是特别得意？」 |
| 猜错了就马上换词、纠正他 | 孩子会觉得「说了也没用」，索性不说了 | 顺着他的版本走：「哦，不是生气，是难过。」 |
| 要求他「好好说，不许哭」 | 哭是这一年龄段最主要的表达通道，堵住就没了入口 | 允许边哭边说：「你哭着我也可以听，慢慢来。」 |
| 自己从不示范，只想让孩子说 | 孩子学的是你的样子，不是你的道理 | 你也说出自己的：「我今天有点累，说话会冲，我先歇两分钟。」 |

## 一句话记住

**他缺的往往不是道理，是词；你先替他说出来，他才学得会自己说。**
